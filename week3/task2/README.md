# Task 2: SQL Query Execution and Documentation

This task runs 50 SQL questions against the classicmodels database and documents the results.

## Contents
- queries.sql: All 50 SQL queries, one per question.
- decompositions.md: Structured breakdown of each question (intent, tables, columns, filters, joins).
- results.txt: Raw psql output for all queries.
- results.md: Formatted results mapped to each question.

## How results were produced
- Queries are executed against the Postgres container (database: mydb).
- Output from psql is captured into results.txt.
- results.md is generated by parsing results.txt and aligning each output block with its query number.
