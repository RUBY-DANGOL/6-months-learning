# Shipping addresses

Covers setting up and changing the address an order is sent to.

## Adding an address
Addresses are managed under Settings, Addresses. One address can be marked as
the default and is preselected at checkout. Business addresses can carry a
company name and a delivery instruction such as a reception desk or gate code.

## Changing the address on an existing order
The address can be changed while the order shows Processing, from Orders,
Change delivery address. Once the order is Picked the address is locked,
because the label has already been printed. At that point the options are to
cancel and reorder, or to redirect the parcel with the courier using the
tracking link, which some couriers charge for.

## Address validation
Addresses are checked against a postal database at checkout. A warning means
the address was not found, which is common for new-build properties. The
address can still be used, but delivery may take longer.

## International shipping
We ship to 34 countries. Duties and import taxes are the recipient's
responsibility unless the checkout states delivered duty paid. PO boxes are not
accepted for express or same-day delivery.

## Wrong address after dispatch
If a parcel has gone to an old address, contact support at once. If the courier
can intercept it, it is redirected free of charge. If it has been delivered, we
open a trace, which takes up to ten working days.
